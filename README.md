# CV - Vishal Patil

LaTeX CV with automated PDF compilation.

## How it works

1. Edit `cv.tex` (directly on GitHub, via push, or through an agent)
2. GitHub Actions automatically compiles it to `cv.pdf`
3. The PDF is committed back to the repo and available as a download

## Manual trigger

You can also trigger compilation manually from the Actions tab > "Compile LaTeX CV" > Run workflow.
